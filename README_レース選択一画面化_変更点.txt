# レース選択一画面化 修正内容

## 修正対象
- docs/static/index.js
- docs/static/style.css

## 変更点

### 1. デザインを前回の柔らかいカード系に戻した
- `keiba_site_visual_polish_complete.zip` をベースに戻した。
- 新聞風の濃い罫線・角ばったUIは使わない構成に戻した。

### 2. トップページのレース選択を一画面向けに変更
- 大きいレースカード一覧をやめ、競馬場ごとのコンパクトな3列表示に変更。
- 各競馬場ごとに 01R〜12R を縦に並べる形式にした。
- PCでは3場を横並びで見られるようにした。
- スマホでも3場を横並びのまま維持し、行高・文字サイズ・余白を詰めた。

### 3. レース選択のリンクを維持
- レース名クリックで出走馬一覧へ移動。
- PCでは右側の「過」「買」ボタンから過去走比較・買い目作成へ移動可能。
- スマホでは画面内に収めるため「過」「買」ボタンは非表示にし、レース名タップを優先。

### 4. 既存機能への影響
- 予想判定ロジックは未変更。
- race.js / past.js / betting.js / analysis_common.js は未変更。
- データJSONの形式は未変更。
- 詳細ページ、過去走比較、買い目作成の機能はそのまま。

## 反映方法
1. zipを解凍
2. `docs/` 配下を現在の `docs/` に上書き
3. ブラウザで Ctrl + F5
